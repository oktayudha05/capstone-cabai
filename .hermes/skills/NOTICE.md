# Atribusi skill pihak ketiga

Folder `.hermes/skills/` berisi skill agen pihak ketiga yang dipakai saat mengerjakan desain proyek ini. Skill ini bukan kode aplikasi; tidak ikut ter-bundle ke hasil build.

## impeccable

- Sumber: https://github.com/pbakaus/impeccable
- Lisensi: Apache License 2.0
- Versi skill: 4.3.1. Mesin `impeccable` 0.1.5 tidak disimpan di repo ini; launcher mengunduhnya sekali ke `~/.impeccable/bin/` saat pertama dipakai.
- Lokasi di repo: `.hermes/skills/impeccable/`
- Dipakai untuk: deteksi anti-pola desain AI, dan aturan craft-floor (kontras, tipografi, motion, permukaan browser).

## antislop

- Sumber: skill pendamping berkas `antislop.md` di akar repo ini.
- Lisensi: lihat `LICENSE-antislop` di akar repo.
- Lokasi di repo: `.hermes/skills/antislop*/`
- Dipakai untuk: filter anti-slop aturan R-01 sampai R-38, plus skill UI, copy, human, mobile, dan komentar kode.
