## antislop

Anti-slop filter: stops generic AI-generated UI, copy, and code comments. Filter, not a style guide — it never picks colors, fonts, or layout. Direction comes from `DESIGN.md` (see below).

Applies to UI, copy, people/accessibility, mobile layout, and code-comment work in this project.

- Core rules (always): `.hermes/skills/antislop/SKILL.md` (same content as `antislop.md` in the repo root)
- UI / visual: `.hermes/skills/antislop-ui/SKILL.md`
- Copy & text: `.hermes/skills/antislop-copywriting/SKILL.md`
- People / accessibility: `.hermes/skills/antislop-human/SKILL.md` (contrast checker: `.hermes/skills/antislop-human/contrast-check.py`)
- Mobile / responsive: `.hermes/skills/antislop-layoutmobile/SKILL.md`
- Code comments: `.hermes/skills/antislop-code/SKILL.md`

Before starting, ask the user when antislop applies: during the work, or after it is done.
Without a `DESIGN.md`, label any UI as "draft without direction" (dials ENERGY 1 / RHYTHM 1 / MOTION 1) — never pass it off as finished.
