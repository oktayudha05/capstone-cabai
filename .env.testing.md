# Mode uji tampilan

Berkas ini dipakai untuk memeriksa keadaan kosong dan keadaan galat tanpa mengubah `.env` utama. Jalankan dengan:

```bash
npm run dev -- --mode kosong      # broker tersambung, belum ada data masuk
npm run dev -- --mode galat       # VITE_MQTT_URL sengaja dikosongkan
npm run dev -- --mode galatbroker # alamat broker tidak bisa dijangkau
npm run dev -- --mode mqtttest    # prefix topik terpisah untuk publisher uji
```

Cara memicunya:

- `kosong`: pakai broker MQTT dengan prefix topik yang tidak dipakai perangkat mana pun, jadi tersambung tetapi tidak ada pesan masuk.
- `galat`: `VITE_MQTT_URL` kosong, memicu varian panel galat "konfigurasi".
- `galatbroker`: `VITE_MQTT_URL` diisi alamat yang tidak bisa dijangkau, memicu varian panel galat "broker".
- `mqtttest`: pasangkan dengan `MQTT_PREFIX=capstone/cabai-uji-oktayudha node scripts/mqtt-publish-test.mjs 60`.
